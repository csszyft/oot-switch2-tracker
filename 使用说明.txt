塞尔达传说：时之笛（Switch 2 重制版）进度助手
==============================================

一、启动方式
------------
- 打包版：解压后双击 `时之笛进度助手.exe`（无需安装 Python）。
- 源码版：安装 Python 3.10 ~ 3.13（勾选 Add Python to PATH 与 tcl/tk），双击 `启动时之笛助手.bat`（排查报错可双击 `启动时之笛助手_调试终端.bat`）。
- 两个版本均在启动进入界面后自动在后台检查 GitHub / Gitee 代码更新，有新版会自动同步并重启；也可随时点击右上角 `🔄` 手动检查，或在 `tracker_config.json` 中将 `"auto_update"` 设为 `false`。
- 先开工具或先开游戏均可自动识别（支持 NX2navi / Fritchii / Hookshot 实时内存与 Eden / Yuzu / Citron / Suyu / Ryujinx 存档）。

二、界面按钮与手柄快捷键
------------------------
- 顶部按钮：`📌` 置顶、`🔄` 检查更新、`📁` 打开目录、`◐` 透明度、`▾/▸` 折叠/展开、`—` 最小化、`✕` 关闭
- PS5 触控板：按下呼出/收起大面板，左右滑切页，上下滑滚动；Amiibo 界面 `L3 + ○` 载入，左右滑切换面具
- 通用/Xbox/Switch 手柄：`L3 + R3` 呼出/收起，`R3 + 十字键←/→` 切页，`R3 + 右摇杆↑/↓` 滚动；Amiibo 界面 `L3 + B` / `L3 + A` 载入
